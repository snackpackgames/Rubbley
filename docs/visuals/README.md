# Visual references

Captures from the running game kept as references for the visual-effects map. They are
not shipped assets.

- `motion-trails.png`, `motion-trails.gif`: fading motion trails behind every moving body
  (white for debris, orange for Rubbley), recorded in the sandbox during a Repel Pulse.
  The trails, the orange marker round Rubbley and the ring where the Pulse fired were
  drawn by a throwaway demo script, not by the game.
